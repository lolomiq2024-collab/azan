# Azan Home — تطبيق أندرويد (WebView ملء الشاشة)
By Loai.miqdadi

يغلّف الصفحة `app/src/main/assets/index.html` داخل تطبيق يعمل بملء الشاشة، ويبقي الشاشة مضاءة،
ويعمل من الريموت، ويشتغل تلقائيًا عند إقلاع الجهاز، ويُظهر شعارًا في قائمة Android TV.

## طريقة بناء ملف APK

### أ) Android Studio (الأسهل)
1. افتح مجلد المشروع من File ▸ Open، وانتظر انتهاء المزامنة (Sync).
2. Build ▸ Build Bundle(s) / APK(s) ▸ Build APK(s).
3. الملف الناتج: `app/build/outputs/apk/debug/app-debug.apk`

### ب) GitHub Actions (بدون تثبيت شيء)
1. أنشئ مستودعًا جديدًا على GitHub وارفع محتويات هذا المجلد كما هي.
2. افتح تبويب Actions ▸ Build APK ▸ Run workflow.
3. بعد دقائق حمّل `AzanHome-apk` من أسفل صفحة التشغيل، وفيه `app-debug.apk`.

## التثبيت على التلفاز
- انسخ الـ APK بفلاش USB، أو ثبّته بتطبيق Downloader / Send Files to TV، وفعّل «مصادر غير معروفة».
- للتشغيل التلقائي عند الإقلاع على أندرويد 10 فما فوق: فعّل لهذا التطبيق
  الإعدادات ▸ التطبيقات ▸ Azan Home ▸ «العرض فوق التطبيقات الأخرى».

## استعماله كلانشر (الشاشة الرئيسية)
من داخل التطبيق: الإعدادات ▸ «اللانشر الرئيسي» ▸ موافق، ثم اختر Azan Home و«دائماً».

بعض الأجهزة (خصوصاً Google TV و Android TV) لا تسمح بتغيير اللانشر من الإعدادات. جرّب من الكمبيوتر عبر ADB:

    adb connect <عنوان-IP-للتلفاز>
    adb shell cmd package set-home-activity com.loai.azanhome/.MainActivity

إن بقي زر Home يفتح اللانشر الأصلي، يمكن تعطيل الأصلي (على مسؤوليتك). اعرف اسمه أولاً:

    adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
    adb shell pm disable-user --user 0 <اسم-حزمة-اللانشر-الأصلي>

ولإرجاعه:

    adb shell pm enable <اسم-حزمة-اللانشر-الأصلي>

تأكد أن Azan Home مثبّت ويعمل قبل التعطيل، وأبقِ اتصال ADB متاحاً. وطالما الأصلي معطّل فلن يفتحه خيار «العودة إلى الشاشة».

## البث المباشر
يعمل في مشغّل مستقل (عملية منفصلة)، فإذا انهارت قناة تعود إلى التطبيق، وفي المحاولة التالية يُجرَّب رابط آخر أو فك ترميز برمجي.

## ملف الرقية (ruqya.mp4)
ضعه في `app/src/main/assets/` بنفس الاسم قبل البناء، فيعمل داخل التطبيق.

## الخروج من التطبيق
زر الرجوع يُمرَّر للصفحة ولا يغلق التطبيق (وضع كشك). اضغط زر الرئيسية (Home) للخروج.

## تحديث الصفحة لاحقًا
استبدل `app/src/main/assets/index.html` بالنسخة الجديدة وأعد البناء.
