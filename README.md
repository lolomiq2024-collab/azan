# Azan Home — تطبيق أندرويد (WebView ملء الشاشة)
By Loai.miqdadi

يغلّف الصفحة `app/src/main/assets/index.html` داخل تطبيق يعمل بملء الشاشة، ويبقي الشاشة مضاءة،
ويعمل من الريموت، ويشتغل تلقائيًا عند إقلاع الجهاز، ويُظهر شعارًا في قائمة Android TV.

## طريقة بناء ملف APK

### أ) Android Studio (الأسهل)
1. افتح مجلد المشروع من File ▸ Open، وانتظر انتهاء المزامنة (Sync).
2. Build ▸ Build Bundle(s) / APK(s) ▸ Build APK(s).
3. الملف الناتج: `app/build/outputs/apk/debug/app-debug.apk`

### ب) GitHub Actions (بدون تثبيت شيء)
1. أنشئ مستودعًا جديدًا على GitHub وارفع محتويات هذا المجلد كما هي.
2. افتح تبويب Actions ▸ Build APK ▸ Run workflow.
3. بعد دقائق حمّل `AzanHome-apk` من أسفل صفحة التشغيل، وفيه `app-debug.apk`.

### توقيع ثابت (كي تُثبَّت التحديثات فوق النسخة السابقة)
أنشئ المفتاح مرة واحدة واحتفظ به في مكان خاص، ولا ترفعه إلى المستودع:

    keytool -genkeypair -keystore debug.keystore -storepass android -keypass android -alias androiddebugkey -keyalg RSA -keysize 2048 -validity 10000 -dname "CN=Azan Home"
    base64 -w0 debug.keystore

انسخ الناتج إلى GitHub: Settings ▸ Secrets and variables ▸ Actions ▸ New repository secret
باسم `DEBUG_KEYSTORE_BASE64`. أول تثبيت بالمفتاح الجديد يحتاج حذف النسخة القديمة.

## التثبيت على التلفاز
- انسخ الـ APK بفلاش USB، أو ثبّته بتطبيق Downloader / Send Files to TV، وفعّل «مصادر غير معروفة».
- للتشغيل التلقائي عند الإقلاع على أندرويد 10 فما فوق: فعّل لهذا التطبيق
  الإعدادات ▸ التطبيقات ▸ Azan Home ▸ «العرض فوق التطبيقات الأخرى».

## استعماله كلانشر (الشاشة الرئيسية)
من داخل التطبيق: الإعدادات ▸ «اللانشر الرئيسي» ▸ موافق، ثم اختر Azan Home و«دائماً».

بعض الأجهزة (خصوصاً Google TV و Android TV) لا تسمح بتغيير اللانشر من الإعدادات. جرّب من الكمبيوتر عبر ADB:

    adb connect <عنوان-IP-للتلفاز>
    adb shell cmd package set-home-activity com.loai.azanhome/.MainActivity

إن بقي زر Home يفتح اللانشر الأصلي، يمكن تعطيل الأصلي (على مسؤوليتك). اعرف اسمه أولاً:

    adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
    adb shell pm disable-user --user 0 <اسم-حزمة-اللانشر-الأصلي>

ولإرجاعه:

    adb shell pm enable <اسم-حزمة-اللانشر-الأصلي>

تأكد أن Azan Home مثبّت ويعمل قبل التعطيل، وأبقِ اتصال ADB متاحاً. وطالما الأصلي معطّل فلن يفتحه خيار «العودة إلى الشاشة».

## أفلام ومسلسلات (يوتيوب)
- تفتح من بلاطة «أفلام ومسلسلات» بملء الشاشة. القوائم تُقرأ من `playlists.json` في مستودع `yt-playlists`، ويمكن إضافة روابط من داخل التطبيق.
- الفيديو يلائم أبعاد أي شاشة ويظهر كاملاً دون قص (قد تظهر حواف سوداء).
- أثناء التشغيل بالريموت: «موافق» تشغيل/إيقاف، ◄► عشر ثوانٍ، ▲ (أو زر القائمة) لاختيار الحلقة، ▼ التالية، رجوع للقائمة.
- عند الأذان يتوقف الفيديو وتظهر شاشة الأذان، وبعد انتهائها (أو إغلاقها) يكمل من حيث توقف.

### أندرويد 5 والأجهزة القديمة
- يضيف التطبيق جذور Let's Encrypt لاتصالاته على أندرويد 7 وأقدم، وإلا تعذّر تحميل القوائم من GitHub.
- التشغيل يعتمد على «Android System WebView». حدّثه من متجر Play (آخر إصدار يدعم أندرويد 5 هو 95).
- إن لم يعمل الفيديو خلال 30 ثانية تظهر رسالة فيها السبب وإصدار WebView.
- `app/src/main/assets/playlists.json` نسخة احتياطية تظهر فقط قبل أول تحميل ناجح.

## البث المباشر
يعمل في مشغّل مستقل (عملية منفصلة)، فإذا انهارت قناة تعود إلى التطبيق، وفي المحاولة التالية يُجرَّب رابط آخر أو فك ترميز برمجي.

## الخروج من التطبيق
زر الرجوع يُمرَّر للصفحة ولا يغلق التطبيق (وضع كشك). اضغط زر الرئيسية (Home) للخروج.

## إدارة القنوات داخل التطبيق (أقسام Live)
- ▲▼ للتنقل بين القنوات، ◄► للتنقل بين الأقسام، «موافق» للتشغيل.
- ضغطة مطوّلة على «موافق» (أو زر القائمة، أو زر «خيارات» باللمس) تفتح: تغيير الاسم، النقل إلى قسم آخر،
  تغيير المكان، الحذف، واسترجاع المحذوفة.
- تعديلاتك تُحفظ على الجهاز وتبقى بعد تحديث القوائم، وتزول إذا حُذف التطبيق أو مُسحت بياناته.

## قائمة القنوات الخاصة
الملف `channels/live.m3u` روابطه تُجرَّب قبل غيرها وقنواته تظهر أولاً في كل قسم.
لإصلاح رابط أو إضافة قناة عدّل الملف من موقع GitHub واحفظ (Commit)، ويقرؤه التطبيق عند فتح قسم Live
(قد يتأخر GitHub بضع دقائق). لا حاجة لبناء APK جديد.

- يقرأ التطبيق الملف من فرع `Tg` إن وُجد فيه، وإلا من `Tg-backup`.
- يجب أن يبقى المستودع عاماً (Public).

## تحديث الصفحة لاحقًا
استبدل `app/src/main/assets/index.html` بالنسخة الجديدة وأعد البناء.
